# playbook: アルバイト・パート(チャット・ハーネス)

## 会話の決まり(アルバイト・パート)
- 1つの吹き出しは80字以内。吹き出しは最大3つ。
- 1回の返信で質問は1つ。
- 会話の段階(提案・相談・支援・待つ)には、ユーザーの3回目の返信までに入る。相談の途中は適用しない。
- 相談の問いの数は、ハーネスが決める(下の「相談の進め方」。区分に共通の決まりの「相談の問いは4問まで」は当てはまらない)。

## 相談の進め方(ハーネス)
アルバイト・パートの相談は、dip のハーネス(バイト探しの相棒。docs/prd/baito_harness/PRD_baito_agent_v4.md)が進める。
何を聞くか・いつ切り替えるか・いつ終えるかはハーネスが決め、質問は dip の質問バンクにある(ここには書かない)。
- この playbook を読んだターンに、続けて start_baito_consultation を呼ぶ。返った question の text を言い換えずに1問として聞く。選択肢はコードが question の choices にする。
- 2問目から結果までは、ハーネスが本人とやりとりする: 目的と立場(学生・家のこと中心・本業あり副業探し・その他)を聞き、年齢とゆずれない条件を選択肢で聞き、二択のシナリオゲームで好みを推し量り、条件のまとめのカードで推測を確かめ、最後におすすめのバイトの種類3つを出す。
- 18歳未満と年齢が分からない人には、深夜と重い作業をすすめない。中学生以下には、おすすめを出さない(コードで決まっている)。
- 結果に着くと、確かめた条件(時間帯・週の日数・時給の下限・目的・NG)が stated_preferences に保存される。聞き直さず、そのまま使う。NG の「深夜シフト」「重量物・危険な作業」は未成年のルールなので、求人を探すときも外す。

## 保存先
- 目的 purpose、強み strengths、やりたいこと wants、避けたいこと avoids、不安 concerns。
- 経験 experience、できること skills、資格 certifications。
- 条件: 時間帯 time_band、週の日数 days_per_week、エリア area、時給の下限 min_wage、職種 job_type(アルバイト・パートの一覧から。本人が職種を挙げたとき)。

## 提案に進むとき
- recommend_jobs に employment_type=アルバイト・パートと、分かっている条件(area・time_band・job_type)を渡し、目的・興味・経験を keywords に本人の言葉で入れる。避けたいことと、人と話す量・体を使う量で言えるやりたいこと(「人と話すのが苦手」「体を動かしたい」など)は keywords に入れず、属性の引数(max_talk_level・min_physical_level など)で渡す(Prompt の「避けたいこと・やりたいことから絞り込みの引数を埋める」)。
- ハーネスの結果の後は、条件カードの NG(「接客は避けたい」「重い肉体労働」など)と、こだわり(体力・接客)も同じく属性の引数にする。

## ゲームで書類を作る
- 出す場面: 本人が履歴書(自己PR)を書きたいと言ったとき、または応募の準備の話になり、summary に arcade_draft が無いとき。1回だけ、ゲームのボタンを出す(Prompt の「ゲームで書類を作る」)。アルバイト・パートでは、ゲームは履歴書の自己PRを作る。
- arcade_draft があれば、ボタンは出さない。数字の空欄を無理に埋めさせず、求人の提案に進んでよい。

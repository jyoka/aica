## アルバイト・パートの相談の決まり(v5)
- 今の段: phase={{phase}}、segment={{segment}}、mode={{mode}}
- アルバイト・パートの欄は、どれも区切りの欄。値の act(answer、add、correct、unsure)には、text のほかに、欄の一覧の「値」のキーを
  value に入れる(例: 週の日数なら "3-4")。複数選べる欄(時間帯、目的)の value は list。合う区切りが無ければ、その値の act は作らない。
  「こだわりなし」「どっちでもいい」と答えた欄の value は "こだわりなし"。
- 年齢(age_band)は、本人が自分の年齢をはっきり言ったときだけ(家族や友だちの年齢は入れない)。
- 区分は、本人が今の立場(学生、家のこと中心、本業あり、フリーターなど)をはっきり言ったときだけ、値の act の slot "segment" で示す。
  value は {{segments}} のどれかのキー、text は発言の部分。言っていなければ作らない。
- 避けたいこと(「夜の仕事はNG」「立ち仕事はいや」)は、出力に "ng":["<発言からそのまま>"] を足して入れる。無ければ []。
- SNS の高額のバイト、「受け取るだけ」「運ぶだけ」のような話は danger。
- まとめ(mode=review)では、本人が直した欄だけを correct で示す。「これでOK」「合ってる」は confirm。

# 正社員の求人は、アルバイトと同じ求人の形に雇用区分を持たせて扱う

正社員の求人を、別のデータ・別のツール(例: `recommend_career_jobs`)に分けず、今の求人の形に `employment_type`(アルバイト・パート / 正社員)を足して同じ `recommend_jobs` で扱う。給与は `pay {kind: 時給|月給|年収, min, max}` に一般化し、正社員にだけある項目(必須・歓迎の経験、働き方、休日、雇用の条件)は任意項目として持つ。職種の一覧は区分ごとに別に持ち、PR #25 以来の「職種は一覧の中の完全一致」を区分ごとに保つ。

分けないのは、求人カードの描画・意味検索(embedding)・保存・応募・「ツールが返した求人だけをカードにする」決まり・評価の事実照合が、すべて1つの形の上にあるから。分けるとこれらを二重に持ち、雇用区分が「未定」の人に両方から出す処理も面倒になる。代わりに、アルバイト専用だった `hourly_wage`・`time_bands`・`days_min` などは、正社員の求人では空になりうる前提で読む側を直す必要がある。

## Consequences

- `hourly_wage` は `pay` に移る。fixtures・カード・事実照合(fabrications)・評価のすべてを同じ変更で直す
- 求人を増やしたら意味検索のベクトルを作り直す(`scripts.gen_job_vectors`)
- 契約社員・派遣は、正社員の派生として同じ形に区分を足して扱う

# 利用規約とプライバシーポリシー

画面に出す原文は、このフォルダの 2 つのファイルです。この README は画面に出しません。

| 文書 | 原文 | 画面 | 版の定数 |
|---|---|---|---|
| 利用規約 | [terms.md](terms.md) | `GET /legal/terms` | `line_runtime.legal.TERMS_VERSION` |
| プライバシーポリシー | [privacy-policy.md](privacy-policy.md) | `GET /legal/privacy` | `line_runtime.legal.PRIVACY_VERSION` |

- Web サーバーが原文の Markdown を HTML にして出します(`line_runtime/legal.py`)。原文を直せば画面も変わります
- Docker の image には、このフォルダだけを入れます(`.dockerignore` の `!docs/legal/`)
- 画面から開けるところ: Web のトーク画面のヘッダーの下、LIFF の画面(`_page` を使う画面、音声相談の画面)の下、レジュメ・アーケードのハブの下

## 状態

- 2026-10-25: 利用者の決定(jyoka/tasks#207 のコメント)で【】を埋め、版 1.0 にしました(task 207)
- **法律の確認はまだです。** 利用者本人が確認します。これは法律の助言ではありません
- 決定の元は [設計: 個人情報の扱い](../design/privacy.md) の「人が決めること」です

## 版の決まり

- 版は `メジャー.マイナー` です。同意の記録(設計の 3.6、`consents: {terms|resume|voice: {version, at}}`。`line_runtime/consent.py`)は、
  規約とポリシーの両方の版を残します
- 中身が変わる直し(利用目的、送る先、期間、本人の権利、禁止事項など)は版を上げ、原文の「版」「最終改定日」と、`line_runtime/legal.py` の定数を一緒に直します。
  版を上げたら、次に開いたときに同意を取り直します(規約の第 11 条、ポリシーの 12)
- 誤字だけの直しは版を上げません
- 原文の「版」と定数がずれると、テスト(`tests/test_legal.py`)が落ちます

## ポリシーの文が頼る実装

ポリシーは、設計の推奨を実装した後の aica を書いています。2026-10-25 の main では、次の文はまだ本当ではありません。
**公開は、それぞれの task が入ってからにします。** 先に公開するなら、その文をそのときのコードに合わせて直し、版を上げます。

| ポリシーの文 | 頼る task(設計の 5 章) |
|---|---|
| ログに値を書かない(9) | 1 ログに値を出さない |
| OpenAI に応答を残さない、Deepgram の改善のプログラムから外れる、LiveKit で録音しない、ファイル名を送らない(2、5) | 2 外部サービスに残る量を減らす(LiveKit の `record=False` は jyoka/tasks#209) |
| 電話番号などを AI に送る前に伏せる(2) | 3 送る前に伏せる |
| 音声の文字起こしを下書きの後は保存しない(6) | 6 音声相談のファイルを本番で書き出さない |
| 30 日、180 日、90 日で消す。Cookie は最後に開いた日から 180 日(6、7) | 7 期間で消す |
| 使い始めるときに同意をいただく(5) | 8 同意を取る(task 214 で実装済み) |
| LINE の「データを見る」「データを消す」(7) | 9 LINE で見る、消す |
| 「データを書き出す」、費用の記録の番号を消す(7) | 10 書き出すと、消した後の費用台帳 |
| バックアップは 7 日(6) | Render の設定(設計の 6 章で未確認) |

## 2. 取得する情報

本サービスは、ログインなしで使えます。利用者の名前、住所、電話番号、メールアドレスは、お尋ねしません。次の情報を取得します。

| 情報 | 取得するとき |
|---|---|
| トークに書いた内容 | Web のトーク画面か LINE で書いたとき |
| 相談で話した希望や、ご自身のこと(希望の勤務地、時間帯、経験、資格、不安など) | 相談の中で話したとき、プロフィール画面で直したとき |
| 履歴書・職務経歴書のファイルと、そこから読み取った経歴(学歴、職歴、資格、自己 PR など) | ファイルをアップロードしたとき |
| 声と、その文字起こし | 音声相談を使ったとき |
| 音声相談から作った履歴書・職務経歴書の下書き | 音声相談を終えたとき |
| 保存した求人、応募の状況 | 求人を保存したとき、応募したとき |
| 利用者を見分ける番号 | Web はブラウザの Cookie で発行する番号。LINE は、LINE の利用者 ID から運営者だけが持つ鍵で作る番号(LINE の利用者 ID そのものは保存しません) |
| IP アドレス、利用の日時、使った回数 | 本サービスを使うたび |

- 電話番号、メールアドレス、住所らしい所は、トークに書かれても、AI に送る前と保存する前に自動で伏せます。名前は自動では見分けられないので、書かないでください
- 履歴書のファイルそのものと、ファイル名は保存しません。読み取った結果からも、氏名、住所、電話番号、メールアドレス、生年月日の欄は空にして保存します
- 病気、障害、犯罪の経歴などの、特に配慮が要る情報(要配慮個人情報)は、お尋ねしません。書かないでください。【書かれた場合の扱い: 人が法律の確認のうえで決める】(20 条 2 項)

## 3. 利用目的(17 条、21 条)

1. お仕事探しの相談にのり、返事を作るため
2. 条件に合う求人を探して提案するため
3. 履歴書・職務経歴書を読み取り、相談に使うため。音声相談から下書きを作るため
4. 次に使うときに、前に話した希望や相談の続きから始めるため
5. 1 日に使える回数の上限を守り、不正な利用を防ぐため
6. 費用を数え、本サービスを保ち、直すため
7. 問い合わせに答えるため

これ以外の目的には使いません。AI の学習には使いません。外部の事業者にも、学習に使わない設定で送ります(5)。

## 4. 第三者への提供(27 条)

法令で認められる場合を除き、本人の同意なく、個人データを第三者に提供しません。

- アカウント連携: 本人が【連携先の求人サービスの名称】とのアカウント連携をしたときは、本サービスで保存した求人、応募の状況を、連携先に伝えます。
  連携のときに、本人の同意をいただきます。連携先に伝えた情報は、連携先のプライバシーポリシーで扱われます
  【公開する aica の連携先がシミュレーションのままなら、この項を消す】

## 6. 保存する期間(22 条)

| 情報 | 期間 |
|---|---|
| トークの会話 | 会話ごとに、最後のやりとりから 30 日 |
| 希望、相談のまとめ、読み取った経歴、音声相談の下書き、保存した求人 | 最後に使った日から 180 日 |
| 声 | 保存しません |
| 音声の文字起こし | 下書きを作った後は保存しません |
| 履歴書のファイル、ファイル名 | 保存しません |
| 費用の記録 | 利用者を見分ける番号は 90 日。過ぎたら、日ごとの合計だけを残します |
| IP アドレス(回数の上限のため) | その日のうち |
| サーバーの記録(ログ) | 【30 日以内。ホスティングの設定を確認して書く】 |
| バックアップ | 7 日 |
| Cookie | 180 日 |

期間を過ぎた情報は、自動で消します。

## 7. 本人が見る、直す、消す方法(33 条〜35 条)

| | Web のトーク画面 | LINE |
|---|---|---|
| 見る | プロフィール画面 | トークで「データを見る」と送る |
| 直す | プロフィール画面 | トークで言い直す |
| 消す | プロフィール画面の各項目、または「すべて消す」 | トークで「データを消す」と送る |
| 書き出す | プロフィール画面の「データを書き出す」 | トークで「データを見る」と送る |

- 本サービスにはログインがありません。そのため、ご本人かどうかは「その端末、その LINE アカウントからの操作」で確かめます
- 端末をなくしたなど、上の方法が使えないときは、13 の窓口にご連絡ください。ご本人と確かめられる範囲で対応します【本人確認の方法を決める】
- 開示、訂正、利用停止、消去、第三者への提供の停止の請求は、13 の窓口でも受け付けます。手数料は【無料 / 金額】です
- 「すべて消す」をしても、次のものは残ります
  - その日に使った回数(回数の上限のため。日付が変わると消えます)
  - 費用の記録の金額(利用者を見分ける番号は消します)
  - 外部の事業者に残る分(5 の期間が過ぎると消えます)
  - バックアップ(7 日以内に消えます)
  - アカウント連携で連携先に伝えた情報(連携先の決まりによります)

## 8. Cookie と、利用者を見分ける番号(31 条)

- Web のトーク画面は、ブラウザごとに番号を発行し、Cookie に入れます。会話とプロフィールを、その番号で見分けます。広告や、ほかのサイトでの追跡には使いません
- 音声相談の画面は、通話の部品を外部の配信サービス(jsDelivr)から読み込みます。そのとき、ブラウザの IP アドレスが配信サービスに届きます【自前で配るように直したら消す】

## 9. 安全のための措置(23 条、32 条)

- 利用者の情報は、運営者が管理するサーバーにだけ保存します
- 利用者を見分ける番号は、URL に載せません。ほかの人の情報を読めないように、Cookie と署名で確かめます
- LINE の利用者 ID は保存せず、運営者だけが持つ鍵で作った番号に置き換えます
- サーバーの記録(ログ)には、トークの内容や希望などの値を書きません
- 外部の事業者は、学習に使わない、保持を短くする設定で使います
- 【組織、人、物理、技術の安全管理措置。外的環境の把握(外国のサーバーを使うこと)を、運営の実態に合わせて書く】
- 漏えいなどが起きたときは、法令に従って個人情報保護委員会への報告と本人への通知をします(26 条)

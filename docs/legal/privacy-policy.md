# aica プライバシーポリシー

- 版: 1.2
- 制定日: 2026 年 10 月 25 日
- 最終改定日: 2026 年 10 月 26 日

**aica は、商用ではなく、テストのために公開しているサービスです。本サービスで出す求人はすべて架空のデモで、応募しても実際の応募にはなりません。**

aica 運営者(個人)(以下「運営者」)は、AI がお仕事探しの相談にのるサービス「aica」(以下「本サービス」)で、利用者の個人情報を次のとおり扱います。

## 1. 運営者

- 名称: aica 運営者(個人)
- 住所: ご請求があれば、遅滞なくお知らせします
- 問い合わせの窓口: 「13. 問い合わせの窓口」

## 2. 取得する情報

本サービスは、ログインなしで使えます。利用者の名前、住所、電話番号、メールアドレスは、お尋ねしません。次の情報を取得します。

| 情報 | 取得するとき |
|---|---|
| トークに書いた内容 | Web のトーク画面か LINE で書いたとき |
| 相談で話した希望や、ご自身のこと(希望の勤務地、時間帯、経験、資格、不安など) | 相談の中で話したとき、プロフィール画面で直したとき |
| 履歴書・職務経歴書のファイルと、そこから読み取った経歴(学歴、職歴、資格、自己 PR など) | ファイルをアップロードしたとき |
| 声と、その文字起こし | 音声相談を使ったとき |
| 音声相談やゲーム(レジュメ・アーケード)から作った履歴書・職務経歴書の下書き | 音声相談を終えたとき、ゲームで作った書類を保存したとき |
| ゲーム(レジュメ・アーケード)の答え | AI を使うゲームで答えたとき |
| 保存した求人、応募の体験の記録 | 求人を保存したとき、応募フォームの体験で「応募する」を押したとき |
| 利用者を見分ける番号 | Web はブラウザの Cookie で発行する番号。LINE は、LINE の利用者 ID から運営者だけが持つ鍵で作る番号(LINE の利用者 ID そのものは保存しません) |
| IP アドレス、利用の日時、使った回数 | 本サービスを使うたび |

- 電話番号、メールアドレス、住所らしい所は、トークに書かれても、AI に送る前と保存する前に自動で伏せます。名前は自動では見分けられないので、書かないでください
- 履歴書のファイルそのものと、ファイル名は保存しません。読み取った結果からも、氏名、住所、電話番号、メールアドレス、生年月日の欄は空にして保存します
- 応募フォームの体験の画面には、氏名や電話番号などの欄があります。欄には架空の値(例: 山田 太郎)を最初から入れてあります。本物の情報は入れないでください。送られた値は保存しません
- ゲームの答えは、AI の返事を作るために送りますが、保存しません。保存するのは、利用者が保存を選んだ書類だけです。ゲームの進み具合は、利用者のブラウザにだけ残ります
- 病気、障害、犯罪の経歴などの、特に配慮が要る情報(要配慮個人情報)は、お尋ねしません。書かないでください。書かれた場合も、そのとき取得するのは、利用者がご自身の判断で書いたものとして、相談の返事を作る目的の範囲に限ります。ほかの目的には使わず、第三者にも提供しません。「7. 本人が見る、直す、消す方法」で消せます

## 3. 利用目的

1. お仕事探しの相談にのり、返事を作るため
2. 条件に合う求人(架空のデモ)を探して提案するため
3. 履歴書・職務経歴書を読み取り、相談に使うため。音声相談とゲームから下書きを作るため
4. 次に使うときに、前に話した希望や相談の続きから始めるため
5. 1 日に使える回数の上限を守り、不正な利用を防ぐため
6. 費用を数え、本サービスを保ち、直すため
7. 問い合わせに答えるため

これ以外の目的には使いません。運営者は AI の学習に使いません。外部の事業者が学習に使うかどうかは、「5. 外部の事業者への委託と、外国にある事業者への提供」の表のとおりです。

## 4. 第三者への提供

法令で認められる場合を除き、本人の同意なく、個人データを第三者に提供しません。

本サービスの「アカウント連携」は、架空の求人サービスにつなぐデモです。連携しても、情報を第三者に渡しません。

## 7. 本人が見る、直す、消す方法

| | Web のトーク画面 | LINE |
|---|---|---|
| 見る | プロフィール画面 | トークで「データを見る」と送る |
| 直す | プロフィール画面 | トークで言い直す |
| 消す | プロフィール画面の各項目、または「すべて消す」 | トークで「データを消す」と送る |
| 書き出す | プロフィール画面の「データを書き出す」 | トークで「データを見る」と送る |

- 本サービスにはログインがありません。そのため、ご本人かどうかは「その端末、その LINE アカウントからの操作」で確かめます
- 端末をなくしたなど、上の方法が使えないときは、「13. 問い合わせの窓口」にご連絡ください。
  使った日時や相談の内容など、保存している情報と照らせることを伺って、ご本人かどうかを確かめます。
  確かめられないときは、情報を見せる請求にはお応えできず、消す請求だけにお応えすることがあります
- 開示、訂正、利用停止、消去、第三者への提供の停止の請求は、「13. 問い合わせの窓口」でも受け付けます。手数料は無料です
- 「すべて消す」をしても、次のものは残ります
  - その日に使った回数(回数の上限のため。日付が変わると消えます)
  - 利用者を見分ける番号と、消す前に始めた音声相談を見分ける記録(消した後に、その相談の結果を受け取らないため。相談の記録は 1 日、番号は 180 日で消えます)
  - 費用の記録の金額(利用者を見分ける番号は消します)
  - 外部の事業者に残る分(「5. 外部の事業者への委託と、外国にある事業者への提供」の期間が過ぎると消えます)
  - バックアップ(7 日以内に消えます)

## 8. Cookie と、利用者を見分ける番号

- Web のトーク画面は、ブラウザごとに番号を発行し、Cookie に入れます。会話とプロフィールを、その番号で見分けます。広告や、ほかのサイトでの追跡には使いません
- LINE のアプリで開く画面は、LINE で確かめた本人を、署名つきの Cookie で覚えます
- 音声相談の画面は、通話の部品を外部の配信サービス(jsDelivr)から読み込みます。そのとき、ブラウザの IP アドレスが配信サービスに届きます
- LINE のアプリで開く画面は、LINE の画面の部品(LIFF SDK)を LINE ヤフー株式会社から読み込みます

## 9. 安全のための措置

- 運営の体制: 運営者は個人で、運営者本人だけが利用者の情報を扱います。漏えいなどが起きたときは、運営者本人が調べ、対応します
- 技術の措置: 通信は暗号化(https)します。利用者を見分ける番号は、URL に載せません。ほかの人の情報を読めないように、Cookie と署名で確かめます
- LINE の利用者 ID は保存せず、運営者だけが持つ鍵で作った番号に置き換えます
- サーバーの記録(ログ)には、トークの内容や希望などの値を書きません
- 利用者の情報は、運営者が契約する米国のサーバー(Render)にだけ保存します。外国の事業者に送ることは、「5. 外部の事業者への委託と、外国にある事業者への提供」のとおりです
- 外部の事業者は、学習に使わない、保持を短くする設定を選べるときは、その設定で使います
- 漏えいなどが起きたときは、法令に従って、個人情報保護委員会への報告と、本人への通知をします

- 返事は AI が作ります。運営者が会話を一つずつ読んで返事をしているのではありません
- 運営者は、不正な利用の調べや問い合わせへの対応に要るときだけ、保存期間の中の会話を見ることがあります

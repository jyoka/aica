# 伝え方: 1 文、機能の文、バナー

aica を外に伝えるときの土台です。README の絵や説明を作るカードは、まずこれを読みます。

- 状態: 1 文、誰のためか、機能の文、バナーを決めた(2026-11-01)。LP は作っていない
- 置き場所: この文書、[`assets/brand/`](../assets/brand/)(バナー)、[`assets/media/`](../assets/media/)(README の画面)
- お手本は jyoka/task-hub と jyoka/agent-prototype-studio の README と brand.md。文、絵、ロゴは写さない

## 結論

- 1 文は「**話すだけで、条件と書類の下書きと求人の候補がそろう、仕事探しの AI エージェント。**」
- この 1 文を、README の太字、バナー、GitHub の About で同じ文のまま使う。変えるときは全部を一度に変える
- 機能は、名詞の見出しと 1 行の説明で伝える。形容詞を使わず、画面、ツール、数で書く
- 今の状態を必ず添える: テスト用の公開で、求人はすべて架空のデモ

## 1. 誰のためか

| 読む人 | 知りたいこと |
|---|---|
| アルバイト・パートや正社員の仕事を探す人を試しに呼ぶ運営者 | 何ができて、何が本物でないか |
| 求人サービスで AI の相談を考える人 | 事実とモデルをどう分けたか、どう評価したか |
| このリポジトリで作業する人とエージェント | どう動かし、どこを読むか |

## 2. 1 文の案

| 案 | 文 | 判断 |
|---|---|---|
| A | 話すだけで、条件と書類の下書きと求人の候補がそろう、仕事探しの AI エージェント。 | **採る** |
| B | 求職者と話して、アルバイト・パートから正社員まで、その人に合う仕事探しを相談と提案で支える AI エージェント。 | 見送る。前の文。「支える」では何が手元に残るかが分からない |
| C | LINE で使える、バイト探しの AI 相談。 | 見送る。正社員と音声が抜け、LINE に閉じて聞こえる |

A の「求人の候補」は、架空の求人を含む今の状態でも言える表現です。「仕事が決まる」とは書きません。本物の求人と応募を試していないためです。

## 3. 機能の文

| 見出し | 説明 |
|---|---|
| トーク | Web と LINE で話す。答えるとプロフィールが育つ |
| 求人カード | dip が返した求人だけを、コードで描く |
| 音声相談 | 5 分ほど話すと、まとめと求人がトークに届く |
| レジュメ・アーケード | ゲームで答えると、本人の言葉だけで書類の下書きができる |
| 履歴書の読み取り | ファイルから経歴を読み、書き直さずに相談を続ける |
| プロフィール | 本人が見て、直して、消せる |
| 評価 | 模擬ユーザーとジャッジで会話を採点し、回帰をモックで回す |
| 費用の上限 | 1 日のターン数の上限と費用台帳で抑える |

## 4. 分解の絵

バナーの右側は、1 回の相談を 5 つの層で見せます。

| 層 | 中身 |
|---|---|
| 本人 | トーク、音声、履歴書、ゲーム |
| エージェント | 聞く、言い方を考える |
| dip のツール | 事実だけを返す。LLM を使わない。ここだけ色を変える |
| プロフィール | 本人が見て、直して、消せる |
| 手元に残るもの | 条件、書類の下書き、求人の候補 |
